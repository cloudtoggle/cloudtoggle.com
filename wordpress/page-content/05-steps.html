How it works

Live in minutes, saving from the first night.

Three steps. No agents to install and no scripts to maintain.

  1. 01

    Connect Your Cloud

    Add an AWS or Azure connection with a guided wizard. Your servers are imported automatically, so there is nothing to install.

    Read the setup guides →
  2. 02

    Create Schedules

    Set the daily and weekly hours each server is needed, in your time zone, and assign the schedule to as many servers as you like.

  3. 03

    Start Saving

    Servers power off outside the hours you chose and back on when they are needed. Override any schedule in seconds when plans change.
